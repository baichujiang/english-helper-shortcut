# iPhone 正式版验收

入口探针已经由用户确认：小白点弹窗关闭后仍在原 App。以下步骤用于验收正式的检查、润色、确认复制和手动粘贴。

## 一次性设置

1. 在快捷指令中确认存在“英文助手 v1.1”。如果只看到“英文助手·入口探针”，需要同步或安装 `dist/英文助手 v1.1.shortcut`。
2. 打开“设置 → 辅助功能 → 触控 → 辅助触控 → 轻点一下”，将入口改为“英文助手 v1.1”。本次已完成绑定。
3. 验收只使用下列合成句子，在新测试草稿或本机临时验收页的输入框中操作，不发送聊天或邮件。
4. 系统首次可能询问是否允许复制。这属于一次性授权，和日常流程分别记录。
5. 若使用 `qa/iphone-smoke.html` 验收页，必须看到“已复制”的反馈再点小白点；只填入句子不会更新剪贴板。测试期间避免在 Mac 复制其他文字，以免通用剪贴板覆盖手机测试输入。

## 检查和替换

在测试草稿输入并复制：

```text
She don't like coffee.
```

点小白点，选“检查：只改错误”。预览应同时包含原文和 `She doesn't like coffee.`。确认后在同一个草稿选中原句并粘贴，应变成修改版。

通过条件：没有进入快捷指令 App 主界面，也不需要切回原 App；粘贴内容与确认的修改版一致。

## 取消保留剪贴板

重新复制原句，点小白点检查，在预览中点“取消”。随后在测试草稿的新位置粘贴，应仍为 `She don't like coffee.`。

取消模式选择菜单也应停止操作，不写入修改版。

## 可选润色

复制以下句子，点小白点，选择“润色：更自然”：

```text
I want to ask you if you can send me the file when you have time.
```

预览应给出保留请求原意的自然表达。模型结果可能不同，不要求固定措辞；确认后应能在同一草稿中粘贴预览中的全文。

## 无变化与输入保护

| 输入 | 预期 |
| --- | --- |
| `Thank you for your help.` | 提示未发现需要修改的地方，保留剪贴板 |
| 只有空格 | 提示先复制英文，停止 |
| `明天下午见。` | 提示没有找到英文字母，停止 |
| 超过1500字符 | 提示分段复制，停止 |

## 覆盖范围与记录

在备忘录完成后，再选一个常用聊天或邮件 App 的未发送草稿重复检查和取消。只记录 App 名、结果、是否切换 App 和必要的合成测试句，不保存真实聊天。

第一版的模型可能合并多行换行，建议按段检查。若模型改动了中文，流程会停止并提示只复制英文部分；不应复制不符合校验的结果。

验收状态写入 `evidence/v1-validation.md`。必须区分操作观察、用户真机反馈和 Mac 测试。
