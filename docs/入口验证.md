# iPhone 小白点入口验证

本阶段不运行 AI。先验证系统入口能否满足“全程不用切换 App”。

## 一次性安装

1. 将 `英文助手·入口探针.shortcut`、`英文助手·剪贴板探针.shortcut` 安装到 iPhone 的快捷指令中。可以通过同一 Apple 账户的快捷指令同步，或在 iPhone 上打开签名文件。
2. 打开“设置 → 辅助功能 → 触控 → 辅助触控”。
3. 启用辅助触控。在“自定顶层菜单”中为探针选择入口，或将轻点两下/长按操作指定为相应快捷指令。以当前系统实际显示的可选操作为准。
4. 如果系统没有列出已安装的探针，不要改成“打开快捷指令 App”或使用 `shortcuts://` 链接代替；记录这一阻碍。

## 第一关：仅显示弹窗

1. 保持一个普通 App 在前台，例如备忘录。
2. 点击小白点，通过已配置的操作运行“英文助手·入口探针”。
3. 观察是否直接出现系统弹窗。
4. 关闭弹窗，确认仍能直接操作原 App。

通过条件：只出现系统菜单/弹窗，未显示快捷指令 App 主界面，也不需要手动切回原 App。

如果系统要求首次授权，单独记录；首次设置与日常运行要分别验收。

## 第二关：菜单、确认复制与粘贴

1. 在原 App 输入并复制：`She don't like coffee.`
2. 从小白点运行“英文助手·剪贴板探针”。
3. 选择“检查入口（固定示例）”。
4. 在预览提示中确认复制。
5. 关闭提示，在原输入框选中测试原句并粘贴。
6. 预期结果为 `She doesn't like coffee.`。
7. 重复步骤，改选“润色入口（固定示例）”。此探针两种入口返回同一个固定句子，仅检查操作流程。

通过条件：读取、菜单、预览、确认、复制、粘贴均正常，整个过程未切换 App。

## 第三关：取消

1. 重新复制原测试句。
2. 启动探针，进入预览后点击“取消”。
3. 在测试区域粘贴，应仍是 `She don't like coffee.`。

通过条件：取消不会改变剪贴板。

## 覆盖范围

先在备忘录完成验收，再选择实际常用的聊天或邮件输入框重复。只在测试草稿中粘贴，不发送消息或邮件。

记录每个场景的系统版本、原 App、启动入口、是否跳转、是否能复制和粘贴、取消后剪贴板是否保留。无需记录真实聊天内容。
